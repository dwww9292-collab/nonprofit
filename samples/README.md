# samples/ — 실제 파일 샘플

**개인정보(대표자 성명·연락처)가 포함되므로 이 폴더의 데이터 파일은 git에 커밋하지 않는다.**
`.gitignore`에서 제외돼 있으니, 아래 절차로 각자 내려받아 채운다.

## 1. 기재부(재정경제부) 공익법인 지정누계 — 2개 분기분 필수

diff 로직이 "직전 분기 대비 신규"를 뽑기 때문에 **연속된 2개 분기**가 반드시 필요하다.

- 출처: https://mofe.go.kr > 법령 > 고시·공고·지침 > "공익법인" 검색
  (기획재정부 → **재정경제부**로 개편, 도메인이 `moef.go.kr`에서 `mofe.go.kr`로 바뀌었다)
- 각 분기 고시 게시글의 첨부 `2.지정누계(YYYY.M.D.).xlsx`
- 저장 파일명: `moef_designation_2026Q1.xlsx`, `moef_designation_2026Q2.xlsx`
- 참고: 이 파일에는 **주소·법인등록번호가 없다.** 지역 정보는 아래 2번 파일과 병합해 채워진다.

## 2. 행정안전부 비영리민간단체 등록현황 (전국)

- 출처: https://www.mois.go.kr 게시판 검색 "비영리민간단체 등록현황"
  (공공데이터포털 data.go.kr에도 같은 자료가 있으나 다운로드에 SSO 로그인이 필요하다)
- 첨부 `(YYYY.M.D.기준) 비영리민간단체 등록현황(중앙 지자체).xls` (약 5.6MB)
- 저장 파일명: `mois_npo_20260331.xls`
- `중앙`/`시도` 두 시트로 나뉘어 있고, 파서가 둘 다 읽는다.

## 3. 기고객 명단 (사내 자료 — 직접 준비)

- 형식: `existing_customers_template.csv` 참조
  (컬럼: 법인명, 법인등록번호, 사업자등록번호, 주소, 사용상품(세미콜론 구분), 비고)
- 저장 파일명: `existing_customers.xlsx` 또는 `.csv`
- 이것이 없으면 이미 거래 중인 곳에도 콜드콜이 나간다. 최우선으로 채울 것.

## 적재 순서 (권장)

주소를 가진 행안부 파일을 먼저 넣어야 기재부 리드가 병합되며 지역이 채워진다.

```
1) 기고객 명단        → 업로드 화면 > 기고객 명단
2) 행안부 NPO         → 업로드 화면 > 공공데이터포털 비영리민간단체
3) 기재부 직전 분기   → period_label 예: 2026Q1
4) 기재부 최신 분기   → period_label 예: 2026Q2  ← 여기서 나온 '신규'가 이번 영업 대상
```
