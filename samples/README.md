# samples/ — 실제 파일 샘플 (전달 전 반드시 채워 넣을 것)

파서 정확도는 실제 파일에 달려 있다. Claude Code에 전달하기 전에 아래 파일을 이 폴더에 넣어라.
**docs/04와 실제 파일이 다르면 이 폴더의 파일이 정본이다.**

## 필수 (없으면 파서 개발 불가)

1. `moef_designation_2026Q1.xlsx` — 기획재정부 최신 분기 「공익법인등 지정·변경 고시」 첨부 지정누계 파일 원본
   - 출처: moef.go.kr > 법령 > 고시·공고·지침 > "공익법인" 검색 > 최신 고시 첨부파일
2. `moef_designation_2025Q4.xlsx` — 직전 분기 파일 (diff 로직 테스트용, 2개 분기가 반드시 필요)
3. `datago_npo_gyeonggi.csv` (또는 xlsx) — 공공데이터포털 비영리민간단체 등록현황 중 시도 1개 파일
   - 출처: data.go.kr에서 "비영리민간단체 등록현황" 검색 후 다운로드
4. `existing_customers.xlsx` — 실제 기고객 명단 (아래 템플릿 컬럼에 맞춰 정리, 민감하면 상위 20건만이라도)

## 템플릿 (이 저장소에 포함됨)

- `existing_customers_template.csv` — 기고객 업로드 형식 정의

## 선택 (있으면 좋음)

- 부처 설립허가 공고 게시글 URL 2~3개와 화면 캡처 (1차 고도화 크롤러 사전 참고용)
- 현재 영업팀이 쓰는 관리 엑셀 1부 (필드 누락 여부 최종 점검용)

## 개인정보 주의

샘플에 대표자 성명·연락처가 포함되면 저장소 접근 권한을 내부로 제한하고, 외부 공유 금지.
