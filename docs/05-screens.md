# 05. 화면 정의 (MVP)

데스크톱 우선(1280px 기준). 좌측 사이드바 내비게이션: 대시보드 / 리드 / 파이프라인 / 데이터 업로드 / 실적 / 설정(ADMIN·MANAGER만).

## 1. 로그인

- email + password. 실패 5회 시 5분 잠금(간단 구현). 성공 시 대시보드로.

## 2. 대시보드 (/)

위젯 6개, 이 순서로:
1. **즉시 배정 필요**: A등급 & 미배정 리드 카운트 + 상위 5건 리스트 (법인명·점수·수집일·[배정] 버튼)
2. **장기 미접촉 경고**: 배정 후 7일 경과 & 활동기록 0건 리드 카운트 + 리스트
3. **신규 리드 유입 추이**: 최근 12주 주별 막대 차트 (소스별 색 구분)
4. **등급 분포**: A/B/C/D 도넛 또는 막대
5. **파이프라인 요약**: 딜 단계별 건수·금액 합계 (가로 퍼널)
6. **이번 분기 수주**: WON 딜 건수·금액, 상품별 분해
- SALES 롤은 1·2·5·6이 본인 담당 기준으로 필터됨.

## 3. 리드 목록 (/leads)

- 테이블 컬럼: [등급배지] 법인명 / 유형 / 지역(시도·시군구) / 설립·지정일 / stage_signal 배지 / 점수 / 상태 / 담당자 / 소스 / 수집일
- 필터 (상단 바): 등급(다중), 상태(다중), 유형(다중), 지역(시도), 소스, 담당자(=미배정 포함), 수집일 범위, "기고객 포함" 토글(기본 off), "중복의심만" 토글
- 기본 정렬: 점수 내림차순 → 수집일 최신순. 컬럼 헤더 클릭 정렬.
- 행 체크박스 → 일괄 배정 (담당자 선택 모달), 일괄 상태변경(ON_HOLD/LOST)
- 우상단: [수기입력 +] 버튼, [CSV 내보내기] (현재 필터 결과, ADMIN·MANAGER만, audit_logs에 EXPORT 기록)
- 페이지네이션 50건/페이지

## 4. 리드 상세 (/leads/:id)

3단 구성:
- **좌: 기본정보** — 법인명(원본), 유형, 주소, 대표자, 연락처, 이메일, 홈페이지 링크, 설립/지정일, 주무관청, 설립목적, 소스 목록(다중 출처 배지), 기고객/중복의심/지정취소가능 배지. [수정] 버튼(담당자·MANAGER·ADMIN).
- **중: 스코어 + 딜** — 점수·등급 크게 표시 + score_breakdown 항목별 막대. 딜 카드 리스트 (상품·단계·금액·확률·예상마감) + [딜 추가]. 외부 검증 링크 버튼 2개: "인터넷등기소에서 확인"(https://www.iros.go.kr 새 탭), "홈택스 공시 확인"(https://www.hometax.go.kr 새 탭) — 자동조회 아님, 단순 링크.
- **우: 활동 타임라인** — 활동기록 역순, [활동 추가] (type, 요약, 다음 액션, 차기 일정). 상태 변경 드롭다운 (LOST 선택 시 사유 모달 필수).
- 상세 진입 시 audit_logs에 VIEW_LEAD_DETAIL 기록 (대표자 개인정보 열람 추적 목적).

## 5. 파이프라인 칸반 (/pipeline)

- 컬럼: CONTACT / MEETING / PROPOSAL / NEGOTIATION / WON / LOST (WON·LOST는 접힘 가능)
- 카드: 법인명, 상품 배지, 금액, 확률, 담당자 아바타, 차기 일정(지났으면 빨간색)
- 드래그앤드롭으로 단계 이동. LOST로 이동 시 사유 모달.
- 상단 필터: 담당자, 상품, 금액 범위. SALES 기본값 = 본인.
- 각 컬럼 헤더에 건수·금액 합계.

## 6. 데이터 업로드 (/ingest) — ADMIN·MANAGER

- 소스 선택 (FILE_UPLOAD 소스만: 기재부 / 공공데이터포털 NPO / 기고객 명단) → 파일 드롭존 → (기재부일 때 period_label 입력)
- 업로드 → 파싱 미리보기 (앞 20행 + 매핑된 필드 표시 + 감지된 문제) → [확정 처리]
- 처리 결과 화면: 총 행수 / 신규 리드 / 병합 / 중복 스킵 / 기고객 / 에러 건수, 에러 행 목록 다운로드
- 하단: 배치 이력 테이블 (일시, 소스, 파일명, period, 결과 통계, 상태)

## 7. 실적 (/performance) — MANAGER·ADMIN (SALES는 본인만)

- 기간 선택 (월/분기)
- 영업사원별 테이블: 배정 리드 수 / 접촉 수 / 접촉 전환율 / 미팅 수 / 제안 수 / WON 건수·금액 / 평균 첫접촉 소요시간
- 상품별 수주 요약

## 8. 설정 (/settings) — ADMIN (스코어링·사용자), MANAGER(조회만)

- **스코어링 가중치**: scoring_settings 테이블 편집 UI (rule_key별 점수 수정) + [전체 재계산 실행] 버튼 (진행상태 표시)
- **사용자 관리**: 생성/비활성화, 롤, 담당 지역(region_codes)
- **소스 관리**: 소스 활성/비활성, 공공누리 유형 메모
- **배정 규칙**: "지역 기반 배정 제안 사용" 토글 — 켜면 배정 모달에서 리드 region_code와 users.region_codes가 일치하는 사원을 상단에 추천 표시 (자동 배정 아님, 제안만)
